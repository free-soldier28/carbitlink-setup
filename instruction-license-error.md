# Окно «Отсутствует регистрация» при подключении — как решить

Если на экране головного устройства (ГУ) при подключении телефона появляется диалог
**«Отсутствует регистрация, обратитесь в службу поддержки клиентов»** (с QR-кодом),
либо в диагностике видно `onLicenseAuthFail errCode = -2, errMsg = {…"msg":
"reg_phone_imei,password\nstatus:-2\n"}`, — это одна и та же проблема.

## Почему это происходит (коротко)

Проверку регистрации делает **не ГУ, а телефон**: приложение CarBitLink при подключении
отправляет HTTP-запрос на сервер лицензий EasyConn (`cmd=reg&hardware_id=…&reg_phone_imei=…`).
Если сервер отвечает статусом, отличным от «1» (не зарегистрировано), телефон отправляет
на ГУ пакет-отказ — и ГУ показывает этот диалог. Само ГУ здесь только отображает результат.

Отсюда три способа решения: один постоянный и два временных.

---

## Способ 1 (рекомендуется): пропатченная версия — окно не появляется вообще

В пропатченной сборке (начиная с **v7 / p7**, актуальная — **v9 / p9**) телефон **никогда
не отправляет на ГУ отказ лицензии**. Результат — тот же, что при выключенном интернете,
но интернет и связь работают нормально. Отключать мобильные данные не нужно.

Сборки публикуются в Telegram-канале: https://t.me/CarbitLink/407

### Установка с компьютера (рекомендуется, 3–5 минут)

1. Возьмите папку **carbitlink-setup** (в ней `setup.bat`, `install.ps1`, папки `apk` и
   `platform-tools` — целиком, ничего не удаляя).
2. На телефоне: Настройки → О телефоне → «Номер сборки» — **7 тапов** → стал разработчиком.
3. Настройки → Для разработчиков → **Отладка по USB** → включить.
4. Подключите телефон **кабелем к ПК**, на запрос «Разрешить отладку по USB?» — Разрешить.
5. Запустите **`setup.bat`** и дождитесь «Готово» — программа установит приложение,
   выдаст разрешения и включит управление с ГУ.
6. Подключите телефон к ГУ — **окно не появится**, интернет можно не выключать.

Проверка: в приложении «О программе» (About) под версией должна быть строка
**`patched: p9`** (или `p7`/`p8`). Если её нет — у вас официальное приложение, см. ниже.

### Установка без компьютера

1. Установите пропатченный APK как обычное приложение (скачать: https://t.me/CarbitLink/407).
2. Если Android 13+ не даёт выдать доступы: страница приложения CarBitLink → меню **⋮** →
   **«Разрешить доступ к ограниченным настройкам»**.
3. Для управления с ГУ: Настройки → Доступность → Скачанные приложения →
   **CarBitLink Accessibility** → включить.

---

## Способ 2 (временный, на официальном приложении): отключить мобильный интернет

Если интернета нет, телефон **не может спросить сервер лицензий** и поэтому **не отправляет
на ГУ отказ** — ГУ просто стартует.

1. Перед подключением телефона к ГУ **выключите мобильные данные** (и Wi-Fi, если он есть).
2. Подключите телефон к ГУ, дождитесь установления соединения.
3. После установления соединения интернет можно включить обратно.

Минус: действие приходится повторять при каждом подключении, пока соединение не установится.

## Способ 3 (временный): сменить среду на предрелизную

Предрелизный сервер лицензий принимает регистрацию без строгой проверки, поэтому окно
не появляется.

1. В CarBitLink откройте «О программе» (About) и **7 раз тапните по версии** —
   откроется инженерный экран (调试).
2. Найдите пункт **«环境切换» / «Сменить среду»**.
3. Выберите **«预发布环境» (Pre-release / Предрелиз)** → «确定 / ОК».
4. **Перезапустите приложение** (настройка действует после перезапуска).
5. Подключитесь к ГУ.

Минус: вместе со средой меняются все серверные адреса приложения — возможны другие
отличия в поведении. Это обход, а не решение.

---

## Примеры

**Пример 1.** На Geely окно «Отсутствует регистрация» появлялось при каждом подключении,
помогало только отключение интернета. Установили v9 через `setup.bat` — теперь подключается
с включённым мобильным интернетом, окна нет.

**Пример 2.** Нужно быстро завести официальное приложение «прямо сейчас» без ПК:
выключить мобильные данные → подключить к ГУ → после соединения включить данные обратно.
На следующий день при переподключении — повторить.

**Пример 3.** В диагностике ГУ видно `onLicenseAuthFail errCode=-2, msg reg_phone_imei,
password status:-2` — это тот же самый случай, лечение идентичное (способ 1 убирает его).

## Если окно всё равно появляется после установки патченной версии

Проверьте в About строку `patched: pN` под версией. Если её нет — на телефоне осталось
официальное приложение: удалите его и установите пропатченное заново (через `setup.bat`
это делается автоматически). Патч работает только на телефоне, менять что-либо на ГУ не нужно.
