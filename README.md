# CarBitLink Setup — установка пропатченных клиентов с ПК по adb

Одна кнопка для пользователя: подключил телефон → запустил `setup.bat` → получил
полностью настроенное пропатченное приложение. Поддерживаются **оба клиента**:

| APK в папке `apk\` | Приложение | Пакет |
|---|---|---|
| `carbitlink-*.apk` | CarBitLink (wws, английский клиент) | `net.easyconn.carman.wws` |
| `yilian-*.apk` | Yilian / Driving Assistant (китайский клиент) | `net.easyconn.carman` |

Скрипт сам определяет приложение по имени APK и выдаёт правильный набор разрешений.

К инструкции приложен **PDF для пользователя**: «Инструкция-установка.pdf» — распечатать или переслать вместе с ZIP. Перегенерация: `py -I -X utf8 tools/make_instruction.py`.

Скачивается одним ZIP: `setup.bat`, `install.ps1`, `platform-tools\` (adb), `apk\`
(пропатченный APK). Ничего ставить на ПК не нужно — работает на Win10/11 из коробки.

## Где лежит APK

Скрипт ищет APK в папке `apk\` рядом с `setup.bat` (при нескольких берёт самый
свежий по дате). Внутри `apk\` есть `README.txt` с этой же памяткой.

Актуальные пропатченные сборки публикуются в Telegram: https://t.me/CarbitLink/407.
- CarBitLink: `carbitlink-6.5.1-patched-vN.apk` (About → `patched: pN`)
- Yilian: `yilian-13.3-patched-vN-signed.apk` (About → `patched: vN`)

APK в git/GitHub **не входят** (180+ МБ): источник — NAS `apk\` уже заполнена
для локальной раздачи, либо приложите APK к GitHub Release / включите в ZIP.

## Для пользователя

1. На телефоне: **Настройки → Для разработчиков → Отладка по USB или Wi-Fi** — включить.
2. Подключить телефон кабелем к ПК, запустить **`setup.bat`**.
3. На телефоне появится запрос «Разрешить отладку по USB?» — **Разрешить**.
4. Скрипт сам: установит APK (с атрибуцией Play Store — см. ниже), выдаст все
   разрешения, добавит в белый список батареи, включит нужные сервисы,
   запустит приложение.
5. Подключить телефон к голове. Готово.

**Режим Wi-Fi:** если кабеля нет — в меню скрипта выбрать «2» и ввести `IP:порт`
из «Для разработчиков → Отладка по Wi-Fi» на телефоне.

### Что именно делает скрипт

- `adb install -r -i com.android.vending <apk>` — установка с атрибуцией Play Store.
  Критично для Android 13+/XOS: sideload-установки (Telegram, файл-менеджер) получают
  флаг «непроверенное приложение», и система блокирует выдачу спец-доступов
  («Доступ для приложения запрещен») и откатывает их у части прошивок (Transsion XOS).
- runtime-разрешения: микрофон, контакты, телефон, уведомления, гео (вкл. фоновое),
  BT, Wi-Fi-соседи, память.
- appops: поверх окон, изменение настроек ( WRITE_SETTINGS — на нём авто-горизонт
  в Yilian).
- `cmd notification allow_listener` — уведомления телефона на голове.
- battery whitelist — чтобы Android не убивал приложение в фоне.
- **Только для CarBitLink**: accessibility (`enabled_accessibility_services`) —
  touch-back с ГУ. В Yilian touch-инжект работает через Presentation-канал
  и accessibility не требует.

Повторный запуск безопасен (идемпотентно). Если на телефоне стоит официальное
приложение (другая подпись) — скрипт предложит удалить его.

## Что даёт пропатченная версия

**Оба клиента:**
- подключение к ГУ любой линии (flavor-гейт открыт) — китайские, английские и пр.;
- окно «Отсутствует регистрация, обратитесь в службу поддержки» не появляется
  (отказ лицензии на ГУ не отправляется);
- «Доступ к истории использования» не требуется.

**Только CarBitLink (wws):**
- драйв-блокировка «недоступна во время вождения» отключена;
- touch-back с ГУ через Accessibility;
- авто-горизонт при зеркалировании + выключатель в инженерном меню (调试);
- инженерный экран переведён (RU/EN по локали);
- строка `patched: pN` под версией + долгое нажатие → список патчей.

**Только Yilian (китайский):**
- управление с ГУ по Wi-Fi работает (серверный флаг перекрыт);
- авто-горизонт: экран телефона горизонтален на всё время зеркалирования;
- строка `patched: vN` под версией + долгое нажатие → список патчей.

## Известные ограничения

- **Touch-back по Wi-Fi**: на некоторых ГУ при включении зеркала показывается
  подсказка «Обратное управление не поддерживается при беспроводном подключении» —
  это просто надпись, тач при этом работает (проверено на CarBitLink patched).
  Если тач по Wi-Fi не работает на конкретной ГУ — подключите кабель.
- **XOS (Infinix/Tecno)**: accessibility у «непроверенных» установок откатывается
  системой при перезапуске приложения — поэтому скрипт всегда ставит с атрибуцией
  магазина; в этом состоянии настройка держится. Касается только CarBitLink
  (Yilian accessibility не использует).
- При установке Yilian поверх официального китайского клиента скрипт предложит
  удалить его — данные приложения сбросятся.
