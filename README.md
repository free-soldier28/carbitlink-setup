# CarBitLink Setup — установка пропатченного CarBitLink с ПК по adb

Одна кнопка для пользователя: подключил телефон → запустил `setup.bat` → получил
полностью настроенное пропатченное приложение (зеркало + touch-back + все разрешения).

К инструкции приложен **PDF для пользователя**: «Инструкция-установка.pdf» — распечатать или переслать вместе с ZIP (перегенерация: PDF built: P:\carbitlink-setup\Инструкция-установка.pdf 127868 bytes).

Скачивается одним ZIP: `setup.bat`, `install.ps1`, `platform-tools\` (adb), `apk\`
(пропатченный APK). Ничего ставить на ПК не нужно — работает на Win10/11 из коробки.

## Для пользователя

1. На телефоне: **Настройки → Для разработчиков → Отладка по USB** — включить.
2. Подключить телефон кабелем к ПК, запустить **`setup.bat`**.
3. На телефоне появится запрос «Разрешить отладку по USB?» — **Разрешить**.
4. Скрипт сам: установит APK (с атрибуцией Play Store — см. ниже), выдаст все
   разрешения, включит Accessibility (touch-back), добавит в белый список батареи,
   запустит приложение.
5. Подключить телефон к голове. Готово.

**Режим Wi-Fi:** если кабеля нет — в меню скрипта выбрать «2» и ввести `IP:порт`
из «Для разработчиков → Отладка по Wi-Fi» на телефоне.

### Что именно делает скрипт

- `adb install -r -i com.android.vending <apk>` — установка с атрибуцией Play Store.
  Критично для Android 13+/XOS: sideload-установки (Telegram, файл-менеджер) получают
  флаг «непроверенное приложение», и система блокирует выдачу accessibility
  («Доступ для приложения запрещен») и откатывает её у части прошивок (Transsion XOS).
- runtime-разрешения: микрофон, контакты, телефон, SMS-уведомления, гео (вкл. фоновое),
  BT, Wi-Fi-соседи, память, уведомления.
- appops: `get_usage_stats` (для прошивок, где движок ещё спрашивает), поверх окон,
  изменение настроек.
- `cmd notification allow_listener` — уведомления телефона на голове.
- accessibility: `enabled_accessibility_services` (с сохранением чужих сервисов) +
  `accessibility_enabled 1` — touch-back с ГУ.
- battery whitelist — чтобы Android не убивал приложение в фоне.

Повторный запуск безопасен (идемпотентно). Если на телефоне стоит официальное
приложение (другая подпись) — скрипт предложит удалить его.

### Известные ограничения

- **Touch-back по Wi-Fi**: голова в clientInfo объявляет `supportBleHid` — если false,
  ГУ не шлёт тачи по радио (диалог «Обратное управление не поддерживается при
  беспроводном подключении»), и никакие настройки телефона это не изменят. По USB-кабелю
  touch-back работает. Телефонная сторона при получении тачей транспорт не проверяет.
- **XOS (Infinix/Tecno)**: accessibility у «непроверенных» установок откатывается
  системой при перезапуске приложения — поэтому скрипт всегда ставит с атрибуцией
  магазина; в этом состоянии настройка держится.
- «Доступ к истории использования» не требуется (патч USAGE_GATE, с p8).

## Для мейнтейнера

- APK: положить актуальный `carbitlink-*-patched-*.apk` в `apk/` (в git не вливается,
  источник — `N:\dev\patched-apks\`). Скрипт берёт самый свежий по дате.
- adb: `platform-tools/` (adb.exe + 2 dll, Apache 2.0) коммитится — репа самодостаточна;
  обновлять по мере надобности с dl.google.com.
- Патчи и сборка APK — репо `P:\carbitlink-patches\`.
- `last-device.txt` — последняя подключённая серия (мусор, игнорируется git).
